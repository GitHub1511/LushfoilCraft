## LushfoilCraft
Created by **Shivin Singh**, with Claude Sonnet 5.5 (Anthropic).

## Built from
- **Lushfoil Photography Sim** - created by Matt Newell, published by Annapurna Interactive. LushfoilCraft runs inside a copy of the game you own;
  nothing from the game is redistributed, and its own credits (including "Created by Matt Newell" and the publisher logo) are left in place.
- **Minecraft: Java Edition 1.21.1** - Mojang Studios, created by Markus "Notch" Persson. Block, item, GUI and skin textures are read from your own
  Minecraft client jar by the tools in `tools/`; none are included in this repository.

The start-up credits screen (Lushfoil / Annapurna | Minecraft / Mojang, then LushfoilCraft), the LushfoilCraft logo (replaces the game's title logo on the loading scene and menus; made by `tools/Gen.cs`), and the window title ("LushfoilCraft - built from Lushfoil Photography Sim and Minecraft - by Shivin Singh", `set_title.ps1`, run by `play.ps1`).
